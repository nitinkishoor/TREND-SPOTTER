# 📈 Stock Chart Pattern & Edge Spotter (100% Python)

A pure-Python computer vision and technical analysis system that takes a stock/crypto chart screenshot, detects edges and price action, identifies classic chart patterns (including **Double Top / "Double Header"**, **Head and Shoulders**, **Double Bottom ("W" pattern)**, **Inverse Head and Shoulders**, and **Triangles**), marks the patterns with necklines and labeled points directly on the image, and computes exact percentage match scores.

---

## ✨ Features

- **100% Python**: Built using OpenCV, NumPy, SciPy, Pillow, Matplotlib, and Streamlit.
- **Edge & Price Action Extraction**:
  - Automatically isolates candlesticks (green/red) and trendline colors from background.
  - Multi-stage Canny edge detection.
  - Morphological kernel filtering to suppress horizontal and vertical chart grid lines.
  - Reconstructs a continuous 1D price curve $y(x)$ across time with Savitzky-Golay noise filtering.
- **Structural Pattern Matcher & Matching Percentage Calculator**:
  - **Double Top ("Double Header")**: Checks peak parity, valley depth, time symmetry, and neckline support breakdown.
  - **Head and Shoulders**: Measures shoulder parity, head prominence, and neckline slope.
  - **Double Bottom ("W" Pattern)**: Measures bottom parity, rebound strength, and neckline resistance.
  - **Inverse Head and Shoulders**: Inverted head with neckline resistance.
  - **Triangles**: Symmetrical, Ascending, and Descending consolidation patterns.
- **Direct Visual Annotations**:
  - Distinct glowing vertices with descriptive labels (`Top 1`, `Top 2`, `Neckline Support`, `Head`, `Left Shoulder`, etc.).
  - Solid/dashed yellow **Neckline** lines.
  - Translucent highlighted bounding boxes around detected patterns.
  - Top header badge showing the pattern name, match percentage, and classification.
- **Dual Interfaces**:
  - **Interactive Web App (Streamlit)**: Drag-and-drop screenshot uploads, sample gallery, sensitivity sliders, pattern filter toggles, scoreboard, and download button.
  - **CLI / Python API**: Run from the command line or integrate into any algorithmic trading system.

## 🚀 Quick Start

### 1. Activate the Virtual Environment

On Windows PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
```

Or using the `.venv` Python executable directly:
```powershell
.\.venv\Scripts\python.exe
```

---

### 2. Launch the Interactive Web App (Streamlit)

```powershell
.\.venv\Scripts\streamlit.exe run app.py
```

This launches the web interface at `http://localhost:8501`.
- **Upload Screenshot**: Drag & drop any screenshot from TradingView, MetaTrader, Binance, Yahoo Finance, Zerodha, etc.
- **Sample Gallery**: Select from pre-loaded sample charts (Double Top, Head & Shoulders, Double Bottom) to test immediately with 1 click.
- **Live Sliders**: Fine-tune the minimum match percentage and peak sensitivity in real-time.
- **Download**: Save marked screenshots with 1 click.

---

### 3. Run from the Command Line (CLI)

Analyze any chart screenshot and save the annotated image:

```powershell
# Analyze Double Top
.\.venv\Scripts\python.exe detector.py --image samples/sample_double_top.png --output annotated_output.png

# Analyze Head and Shoulders
.\.venv\Scripts\python.exe detector.py --image samples/sample_head_and_shoulders.png --output annotated_output.png

# Analyze Double Bottom with custom threshold
.\.venv\Scripts\python.exe detector.py --image samples/sample_double_bottom.png --min_match 70.0
```

---

### 4. Use as a Python Module

```python
from detector import ChartPatternDetector
from PIL import Image

# Initialize detector
detector = ChartPatternDetector(min_match_percentage=65.0)

# Run detection
result = detector.detect_from_image("path/to/chart_screenshot.png")

# Inspect detected patterns
for pattern in result["patterns"]:
    print(f"Pattern: {pattern.name}")
    print(f"Match: {pattern.match_percentage}%")
    print(f"Type: {pattern.pattern_type}")
    print(f"Metrics: {pattern.metrics}")

# Save or display annotated image
annotated_pil = Image.fromarray(result["annotated_image"])
annotated_pil.save("annotated_chart.png")
```
